## 4) 风险

1. **G1 的 +7.4pp 不能归因为 batch 本身**。G0/G1 的训练样本暴露量、RNG 都不同，有效 batch32 是 micro8×4 堆出来的；要拆出 batch 效应需要单独控制变量的重训（本轮明确不做）。
2. **held-out 只相对本轮 PnP 采数独立**，不相对 A 的既有训练数据。task2 的 50 个初态里有 31 个是按预先写死的规则生成的 native-reset 状态，和其他任务的“纯现有初态”性质不同。
3. **state 编码沿用已批准的非官方 xyz+四元数+单 gripper 协议**，所以这些数字是内部横向比较，不能对外宣称是官方 benchmark 分数。
4. **每任务 50 次有抽样不确定性**：总体 ±2–4pp 量级的差异要谨慎解读，task 级别的极端值（0/50、50/50）尤其如此。
5. 这是单 suite（`libero_spatial`）、单 seed、单轮，不能外推到 Object/Goal/Long。
6. 交付侧：报告与证据在工作区已落地，是否同步到 GitHub 以编排侧推送记录为准（本轮未做任何重训/重评）。
